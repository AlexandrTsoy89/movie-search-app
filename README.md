# Movie Search Application

A movie search application built with Next.js, TypeScript,
Ant Design, and The Movie Database (TMDB) API.

## Live Demo

[View deployed application](https://movie-search-app-bice-eta.vercel.app)

## Features

- Movie search
- Pagination
- Movie ratings
- Rated movies list
- Movie genres
- Responsive layout
- Error handling and loading states

## Technologies

- Next.js
- React
- TypeScript
- Ant Design
- Tailwind CSS
- TMDB API
- ESLint, Prettier, Husky

## Getting Started

1. Clone the repository.
2. Run `npm install`.
3. Create `.env.local`.
4. Add `TMDB_ACCESS_TOKEN=your_token`.
5. Run `npm run dev`.
